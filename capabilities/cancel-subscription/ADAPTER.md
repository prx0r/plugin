# Cancel Subscription — adapter plan (no fork)

Source kernel stays in `prx0r/cancelme` (API + MCP + verification workers +
`data/services` + `data/evidence`). This repo will only ever hold the
surface wrapper:

```text
capabilities/cancel-subscription/
  adapter.ts        calls cancelme API/MCP, translates to Offer/DomainResult-style truth states
  tools.ts          find_cancellation_steps + identify_subscription_charge ONLY
  evals/            name-variant corpus (Cancel Subscription vs CancelMe …)
  submission/       packet generated by studio creator
```

Rules: guide-only v1 (no autonomous cancellation); evidence/confidence map
to quality inputs, never invented; verification-ladder states
(documented → … → field_verified, stale, unknown) pass through verbatim —
a studio may change presentation, never epistemic strength. Bug fixes go
upstream; this directory contains zero resolver logic.
